# Volta AC-22 installer manual (excerpt)

- F17: socket shutter or lock fault on a Type 2 socket. UnlockConnector, then replace the lock actuator.
- F03: earth fault / insulation fault (RCD tripped). Safety stop. Never reset remotely; an electrician must inspect.
- Firmware 5.1.0 changes the RFID driver; if cards stop working after the update, reset the station.
- No contactless terminal is fitted; drivers start by card or app.
